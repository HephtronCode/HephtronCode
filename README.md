## 🏆 Flagship: FinVault Engine

Real-time fraud detection for financial transactions. Rule-based systems generate ~95% false positives, so FinVault replaces them with behavioral profiling, velocity checks, and graph-based entity resolution.

- **40% fewer** false-positive alerts
- **Sub-50 ms** inference latency at 10K TPS
- **$2.3M+** potential fraud prevented in pilot

**Stack:** TypeScript · Redis Streams · PostgreSQL · ML pipelines · Kubernetes

[Repository](https://github.com/HephtronCode/FinVault-Fraud-detection-engine) · [Architecture docs](https://github.com/HephtronCode/FinVault-Fraud-detection-engine#architecture)
